   a) Run: supabase/migrations/009_quiz_system.sql

      ✓ Sets up Row Level Security policies

STEP 2: Create a Quiz Round (Quick Test)
═══════════════════════════════════════════════════════════════

Option A: Using SQL (Fastest for testing)
------------------------------------------

1. First, get your event ID:
   
   SELECT id, name FROM events ORDER BY created_at DESC LIMIT 5;

2. Open: scripts/create-test-quiz-round.sql

3. Replace 'YOUR_EVENT_ID' with your actual event ID (appears 2 times)

4. Replace 'ROUND_ID' with the round ID after creating the round (appears 4 times)

5. Run the SQL script in Supabase SQL Editor

This creates:
- 1 quiz round named "Round 1: Prompt Engineering Quiz"
- 3 sample questions (2 single-answer, 1 multi-select)
- 4 options per question with correct answers marked


Option B: Using Admin UI (More visual)
---------------------------------------

1. Login as admin
2. Go to Admin → Rounds Manager
3. Click "Create Round"
4. Fill in:
   - Name: "Round 1: Prompt Engineering Quiz"
   - Type: QUIZ
   - Duration: 30 minutes
   - is_active: true

6. Go to Admin → Quiz Manager
7. Select your round
8. Click "Add Question" and create questions manually

STEP 3: Import Full Question Banks (Optional)
═══════════════════════════════════════════════════════════════

To import all questions from the HTML files:

1. Make sure you have Node.js and tsx installed:
   npm install -g tsx

2. Get your round IDs:
   
   SELECT id, name FROM rounds WHERE type = 'QUIZ';

3. Set environment variables:

   Windows PowerShell:
   $env:VITE_SUPABASE_URL = "your_supabase_url"
   $env:VITE_SUPABASE_ANON_KEY = "your_anon_key"
   $env:ROUND_2ND_YEAR_ID = "uuid_for_2nd_year_round"
   $env:ROUND_4TH_YEAR_ID = "uuid_for_4th_year_round"

4. Run the seed script:
   tsx scripts/seed-quiz-questions.ts

This imports:
- 30 questions for 2nd year (Prompt Engineering)
- 29 questions for 4th year (Advanced Agentic AI)

═══════════════════════════════════════════════════════════════
TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

Problem: "Loading rounds..." stuck forever
Solution: 
  - Check if you have an active event
  - Check console for errors
  - Verify rounds exist: SELECT * FROM rounds;
  - Make sure team is logged in

Problem: "No rounds available"
Solution:
  - Create a round with type='QUIZ' and is_active=true
  - Verify event_id matches current event

Problem: Quiz won't start
Solution:
  - Check round is_active is true
  - Verify questions exist for the round:
    SELECT COUNT(*) FROM quiz_questions WHERE round_id = 'YOUR_ROUND_ID';
  - Check browser console for errors

Problem: Answers not saving
Solution:
  - Check RLS policies are applied
  - Verify team has an active session
  - Check browser console for database errors

Problem: Timer shows wrong time
Solution:
  - Timer duration comes from rounds.duration_minutes
  - Update the round: UPDATE rounds SET duration_minutes = 30 WHERE id = 'ROUND_ID';

DATABASE QUERIES FOR DEBUGGING
═══════════════════════════════════════════════════════════════

-- Check rounds
SELECT id, name, type, is_active, duration_minutes 
FROM rounds 
WHERE type = 'QUIZ' 
ORDER BY order_index;

-- Check questions for a round
SELECT qq.question_number, qq.question_text, qq.question_type, qq.points,
       COUNT(qo.id) as option_count
FROM quiz_questions qq
LEFT JOIN quiz_options qo ON qq.id = qo.question_id
WHERE qq.round_id = 'YOUR_ROUND_ID'
GROUP BY qq.id, qq.question_number, qq.question_text, qq.question_type, qq.points
ORDER BY qq.question_number;

-- Check quiz sessions for a team
SELECT qs.*, r.name as round_name
FROM quiz_sessions qs
JOIN rounds r ON qs.round_id = r.id
WHERE qs.team_id = 'YOUR_TEAM_ID'
ORDER BY qs.started_at DESC;

-- Check answers for a session
SELECT qa.*, qq.question_number, qq.question_text
FROM quiz_answers qa
JOIN quiz_questions qq ON qa.question_id = qq.id
WHERE qa.round_session_id = 'YOUR_SESSION_ID'
ORDER BY qq.question_number;

-- Recalculate score for a session
SELECT calculate_quiz_score('YOUR_ROUND_SESSION_ID');
