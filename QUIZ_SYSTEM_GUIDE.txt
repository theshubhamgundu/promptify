🚀 DEPLOYMENT STEPS
═══════════════════════════════════════════════════════════════════

STEP 1: Apply Database Migrations
──────────────────────────────────

You need to run the SQL migrations in the Supabase SQL Editor:

1. Go to your Supabase Dashboard: https://app.supabase.com
2. Select your project
3. Click on "SQL Editor" in the left sidebar
4. Click "New Query"
5. Copy the contents of these files ONE AT A TIME:
   
   a) First: supabase/migrations/009_quiz_system.sql
      - Paste the entire file content
      - Click "Run" button
      - Verify: No errors, should see "Success"
   
   b) Second: supabase/migrations/010_quiz_rls.sql
      - Paste the entire file content
      - Click "Run" button
      - Verify: No errors, should see "Success"

STEP 2: Verify Tables Created
──────────────────────────────

1. In Supabase Dashboard, click "Table Editor"
2. You should see these new tables:
   ✓ quiz_questions
   ✓ quiz_options
   ✓ quiz_answers
   ✓ quiz_sessions

STEP 3: Create Quiz Rounds
──────────────────────────────

Before importing questions, you need to create rounds in your database:

1. Go to Supabase SQL Editor
2. Run this query to create the 2nd year round:

   INSERT INTO rounds (event_id, name, description, type, order_index, duration_minutes, scoring_config)
   VALUES (
     '<YOUR_EVENT_ID>',
     'Round 1 - Prompt Engineering Quiz (2nd Year)',
     '30 questions on prompt engineering fundamentals',
     'QUIZ',
     1,
     45,
     '{"base_points": 1, "multi_select_bonus": 1}'::jsonb
   )
   RETURNING id;

3. Save the returned ID as ROUND_2ND_YEAR_ID

4. Run this query to create the 4th year round:

   INSERT INTO rounds (event_id, name, description, type, order_index, duration_minutes, scoring_config)
   VALUES (
     '<YOUR_EVENT_ID>',
     'Round 1 - Agentic AI Quiz (4th Year)',
     '29 questions on advanced AI agent concepts',
     'QUIZ',
     2,
     50,
     '{"base_points": 1, "multi_select_bonus": 1}'::jsonb
   )
   RETURNING id;

5. Save the returned ID as ROUND_4TH_YEAR_ID

STEP 4: Seed Quiz Questions
──────────────────────────────

Option A - Manual Import (Recommended for first time):
1. Go to Admin > Quiz Manager in your application
2. Select the round
3. Click "Add Question" for each question
4. Manually enter question text, options, and mark correct answers
5. This is tedious but gives you full control

Option B - Automated Import (Advanced):
1. Install Node.js dependencies if not already:
   npm install tsx @supabase/supabase-js

2. Set environment variables:
   SET VITE_SUPABASE_URL=<your-supabase-url>
   SET VITE_SUPABASE_ANON_KEY=<your-anon-key>
   SET ROUND_2ND_YEAR_ID=<round-id-from-step-3>
   SET ROUND_4TH_YEAR_ID=<round-id-from-step-3>

3. Run the seed script:
   npx tsx scripts/seed-quiz-questions.ts

4. Verify in Supabase Table Editor that questions are loaded

STEP 5: Build and Deploy Frontend
──────────────────────────────────

1. Build the application:
   npm run build

2. The quiz pages are now accessible:
   - Participants: /quiz-<round-id>
   - Results: /quiz-results-<round-id>
   - Admin: Admin > Quiz Manager

📚 HOW TO USE
═══════════════════════════════════════════════════════════════════

FOR ADMINISTRATORS:
──────────────────────

1. Managing Questions:
   - Go to Admin Dashboard
   - Click "Quiz Manager" in sidebar
   - Select a round from dropdown
   - Add/Edit/Delete questions as needed

2. Monitoring Progress:
   - View quiz_sessions table to see team progress
   - View quiz_answers table to see individual answers
   - Use calculate_quiz_score() function to recalculate scores

FOR PARTICIPANTS:
──────────────────

1. Starting a Quiz:
   - Navigate to the quiz round from dashboard
   - Quiz session starts automatically
   - Timer begins countdown

2. Taking the Quiz:
   - Read each question carefully
   - Click options to select answers
   - For multi-select questions, you can select multiple options
   - Answers are auto-saved as you go
   - Use navigation buttons or question numbers to move around

3. Submitting:
   - Click "Submit Quiz" on the last question
   - Confirm your submission
   - Quiz is automatically graded
   - View your results immediately

🔍 QUESTION FORMATS
═══════════════════════════════════════════════════════════════════

The system supports two HTML files:

1. Prompt_Engineering_Question_Bank.htm
   - 30 questions for 2nd year students
   - Mostly single answer (A, B, C, D)
   - Focuses on prompt engineering basics
   - Each question worth 1 point

2. 4thyrs.htm
   - 29 questions for 4th year students
   - Mix of single and multi-select
   - Focuses on agentic AI and advanced concepts
   - Single answer: 1 point
   - Multi-select: 2 points

═══════════════════════════════════════════════════════════════════
📊 SCORING SYSTEM
═══════════════════════════════════════════════════════════════════

Single Answer Questions:
- 1 point if correct
- 0 points if incorrect

Multi-Select Questions:
- 2 points if ALL correct options selected
- 0 points if ANY incorrect option selected or missing correct option
- Partial credit NOT supported (all or nothing)

Final Score:
- Sum of all points earned
- Stored in quiz_sessions.total_score
- Also updated in round_sessions.score for leaderboard

═══════════════════════════════════════════════════════════════════
🛠️ TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════

Problem: Questions not loading
Solution: Check that round_id exists and has quiz_questions

Problem: Cannot submit answers
Solution: Verify RLS policies are applied, check browser console

Problem: Timer not working
Solution: Check useTimer hook, verify round.duration_minutes is set

Problem: Scores not calculating
Solution: Run calculate_quiz_score() function manually in SQL Editor

Problem: Import script fails
Solution: Verify environment variables are set correctly

═══════════════════════════════════════════════════════════════════
📈 DATABASE SCHEMA REFERENCE
═══════════════════════════════════════════════════════════════════

quiz_questions
├── id (UUID, PK)
├── round_id (UUID, FK → rounds)
├── question_number (INTEGER)
├── question_text (TEXT)
├── question_type ('SINGLE_ANSWER' | 'MULTI_SELECT')
├── image_url (TEXT, optional)
├── points (INTEGER)
└── order_index (INTEGER)

quiz_options
├── id (UUID, PK)
├── question_id (UUID, FK → quiz_questions)
├── option_label (TEXT, e.g., 'A', 'B', 'C', 'D')
├── option_text (TEXT)
├── is_correct (BOOLEAN)
└── order_index (INTEGER)

quiz_answers
├── id (UUID, PK)
├── team_id (UUID, FK → teams)
├── round_session_id (UUID, FK → round_sessions)
├── question_id (UUID, FK → quiz_questions)
├── selected_options (TEXT[], e.g., ['A'] or ['A', 'C'])
├── is_correct (BOOLEAN)
├── points_earned (INTEGER)
└── answered_at (TIMESTAMPTZ)

quiz_sessions
├── id (UUID, PK)
├── team_id (UUID, FK → teams)
├── round_id (UUID, FK → rounds)
├── round_session_id (UUID, FK → round_sessions)
├── started_at (TIMESTAMPTZ)
├── submitted_at (TIMESTAMPTZ)
├── time_remaining_seconds (INTEGER)
├── total_score (INTEGER)
├── total_questions (INTEGER)
├── correct_answers (INTEGER)
└── status ('IN_PROGRESS' | 'SUBMITTED' | 'GRADED')

💡 TIPS & BEST PRACTICES
═══════════════════════════════════════════════════════════════════

1. Test with a dummy team before live event
2. Export questions as backup before making bulk changes
3. Set realistic timer durations (45-60 minutes for 30 questions)
4. Review all questions for typos before going live
5. Monitor quiz_sessions table during live event
6. Have a backup plan if system fails (paper backup)
7. Communicate quiz rules clearly to participants
8. Test on different devices (desktop, mobile)
