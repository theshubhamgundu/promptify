═══════════════════════════════════════════════════════════════
  QUIZ SYSTEM - CODE-BASED (NO DATABASE FOR QUESTIONS)
═══════════════════════════════════════════════════════════════

The quiz questions are now stored in the CODE, not the database.
This is simpler and doesn't require running SQL scripts.

═══════════════════════════════════════════════════════════════
HOW IT WORKS
═══════════════════════════════════════════════════════════════

✓ Questions stored in: src/data/quiz-questions.ts
✓ Quiz logic in: src/pages/QuizRoundSimple.tsx
✓ No database migrations needed for questions
✓ Everything works without Supabase setup

═══════════════════════════════════════════════════════════════
TO TEST THE QUIZ NOW
═══════════════════════════════════════════════════════════════

1. Create a simple round in database (just the round, no questions):

   INSERT INTO rounds (
       event_id,
       name,
       description,
       type,
       order_index,
       duration_minutes,
       is_active,
       scoring_config
   ) VALUES (
       'YOUR_EVENT_ID'::uuid,
       'Quiz Round 1',
       'Prompt Engineering Quiz',
       'QUIZ',
       1,
       30,
       true,
       '{}'::jsonb
   );

2. Login as participant
3. Go to Rounds → Click "Start Quiz"
4. Quiz loads questions from code (not database)

ADDING MORE QUESTIONS

Edit: src/data/quiz-questions.ts

Add to PROMPT_ENGINEERING_QUESTIONS array:

{
  id: 'pe-q6',
  questionNumber: 6,
  questionText: `Your question text here...`,
  questionType: 'SINGLE_ANSWER', // or 'MULTI_SELECT'
  points: 1,
  options: [
    { label: 'A', text: 'Option A text' },
    { label: 'B', text: 'Option B text' },
    { label: 'C', text: 'Option C text' },
    { label: 'D', text: 'Option D text' }
  ],
  correctAnswers: ['B'] // Single answer
  // or correctAnswers: ['A', 'C'] // Multiple answers
},

Save the file and rebuild: npm run build

═══════════════════════════════════════════════════════════════
SCORING
═══════════════════════════════════════════════════════════════

Currently scoring happens in the frontend only.
Results are NOT saved to database (stateless).

To save results to database:
- Keep the quiz_sessions and quiz_answers tables
- Call Supabase from QuizRoundSimple.tsx to save
- Or keep it stateless for practice quizzes
