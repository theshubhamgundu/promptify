OPTION 1: Fastest Way (Auto-creates everything)
------------------------------------------------

1. Open Supabase Dashboard → SQL Editor
2. Copy and paste: scripts/QUICKSTART_QUIZ.sql
3. Click "Run"
4. Note the Event ID shown in the output
5. In your app, set that event as current
6. Login as a participant → Go to Rounds → Start Quiz

✅ Done! This creates:
   - 1 test event
   - 1 quiz round (15 min, 3 questions)
   - All questions with correct answers


OPTION 2: Use Your Existing Event
----------------------------------

1. Get your event ID:
   
   SELECT id, name FROM events ORDER BY created_at DESC;

2. Open: scripts/STEP_BY_STEP_QUIZ_SETUP.sql

3. Follow the 4 steps in that file:
   - Step 1: Find event ID (you already have it)
   - Step 2: Create round (paste your event ID)
   - Step 3: Add questions (paste the round ID)
   - Step 4: Verify

✅ This creates a quiz round in YOUR existing event


TROUBLESHOOTING
---------------

Problem: "Loading rounds..." forever
Fix: 
  - Check browser console for errors
  - Verify event exists: SELECT * FROM events;
  - Make sure you're logged in
  - Check that event is set in app

Problem: No rounds showing
Fix:
  - Run: SELECT * FROM rounds WHERE type = 'QUIZ';
  - Make sure is_active = true
  - Verify event_id matches your current event

Problem: Quiz won't start
Fix:
  - Check questions exist:
    SELECT COUNT(*) FROM quiz_questions 
    WHERE round_id = 'YOUR_ROUND_ID';
  - Must have at least 1 question

Problem: Can't see correct answers
Fix:
  - This is normal! Correct answers show on results page
  - Or admin can enable show_correct_answers in scoring_config

DATABASE QUERIES FOR DEBUGGING
-------------------------------

-- Check your events
SELECT id, name, status FROM events;

-- Check quiz rounds
SELECT id, name, type, is_active, duration_minutes 
FROM rounds WHERE type = 'QUIZ';

-- Check questions for a round
SELECT question_number, question_type, points, 
       LEFT(question_text, 50) as preview
FROM quiz_questions 
WHERE round_id = 'YOUR_ROUND_ID'
ORDER BY question_number;

-- Check if team has taken quiz
SELECT * FROM quiz_sessions 
WHERE team_id = 'YOUR_TEAM_ID';

-- View answers
SELECT qa.*, qq.question_number
FROM quiz_answers qa
JOIN quiz_questions qq ON qa.question_id = qq.id
WHERE qa.team_id = 'YOUR_TEAM_ID';
